# Satoshi Shelf worker — secure BTC-gated delivery

This Cloudflare Worker verifies Bitcoin payments **server-side** and only then
serves the product file. Files are AES-256-GCM encrypted into the Worker bundle
at build time and are **never** published as plaintext in the public repo.

## How it works

```
buyer pays BTC
   -> POST /verify  { productId, txid }
        worker fetches live BTC price, looks up the tx on mempool.space,
        checks a vout pays your address >= the product price,
        returns a 15-minute signed token (HMAC)
   -> GET  /download?token=...   -> the file, decrypted on the server
```

Plaintext files are stored in `../products/` — **gitignored**. The build compiles
them into encrypted `src/embedded.js` (also gitignored) and writes a public-safe
copy to `../secure/catalog.enc.json`. That encrypted catalog can be committed to
GitHub: without the private key (held only by the worker) it is unreadable, so
nobody can download your products without paying. No MediaFire or file host needed.

## One-time setup

```bash
cd worker
npm install                 # installs wrangler
npx wrangler login          # opens browser, authorises Cloudflare (free account)
```

Generate the encryption key and embedded bundle:

```bash
npm run build               # creates worker/.shelfkey (PRIVATE — back it up)
```

`BTC_ADDRESS` is set in `wrangler.toml`. A plain `wrangler deploy` works with
zero configuration — signing + decryption keys fall back to the private key in
the build bundle. You may optionally harden with:

```bash
npx wrangler secret put DOWNLOAD_SECRET   # download-link signing key
npx wrangler secret put SHELF_KEY         # deliverable decryption key
```

## Deploy

```bash
npm run deploy
```

You'll get a URL like:

```
https://satoshi-shelf.<your-subdomain>.workers.dev
```

**Paste that URL into `assets/products.js` as `workerUrl`**, commit, and push.
The store then uses secure delivery automatically.

## Local dev / test

```bash
npm run dev     # builds embedded.js then runs a local worker
npm test        # unit tests (incl. AES-GCM roundtrip)
node integration.test.mjs   # end-to-end verify + decrypt + download
```

## Notes

- `src/embedded.js` (encrypted product blobs + private key) is generated by
  `build.mjs` and is **gitignored** — never commit it. Same for `.shelfkey` and
  `../products/`.
- `../secure/catalog.enc.json` is the *encrypted* catalog — safe to commit.
- Tokens expire after 15 minutes and are signed, so `/download` can't be called
  without a genuine payment.
- To stop one txid being shared by many buyers, add a KV namespace and record
  used txids in `/verify`. Ask if you want this added.
