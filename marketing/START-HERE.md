# PART A — Make your first video (about 20 minutes)

We'll use **CapCut Web** (free, works in the browser). If it asks you to log in, use Google/email — free.

### A1. Open the editor
1. Go to **capcut.com** in your browser.
2. Click **Sign up / Log in** (Google login is fastest).
3. Click **Create project** → it opens an editor.

### A2. Set it vertical (9:16)
1. Find the **ratio / format** control (top or right side) → choose **9:16 (1080×1920)**.

### A3. Build the 6 beats
You'll make 6 quick scenes, one per line from the script (see `FIRST-VIDEO.md`).

1. **Get background clips.** Open a new tab → **pexels.com** → search `laptop typing`, `notebook writing`, `spreadsheet`, `phone`. Download 4–5 short clips (free). *(Or skip this and use solid-color backgrounds with text.)*
2. Back in CapCut, **drag clip #1** onto the timeline. Trim it to ~3 seconds.
3. **Add the hook text:** click **Text → Add text**. Type:
   `3 SIDE HUSTLES YOU CAN START TODAY WITH $0`
   Make it **big and bold**, centered. Drag the text clip to cover the first 2–3 seconds.
4. **Repeat** for each beat — drag a new background, add a new text box:

   | Beat | Text |
   |---|---|
   | 2 | `#1 — WRITE A GUIDE OR CHECKLIST` |
   | 3 | `#2 — FREELANCE A SKILL YOU HAVE` |
   | 4 | `#3 — SELL A TEMPLATE YOU ALREADY USE` |
   | 5 | `ALL $0. NO INVENTORY.` |
   | 6 | `FREE 7-DAY PLAN — LINK IN BIO` |

5. Each text box: ~3 seconds. Total ≈ 25–30 seconds.

### A4. Voiceover (optional but better)
- Easiest: in CapCut click **Text → Text to speech**, select a text box, pick a voice. Do it for each beat.
- Or record your own voice over the timeline (mic button).
- Or skip voice and rely on text + music. Still works.

### A5. Captions + music
1. **Captions:** click **Captions → Auto captions** → Generate. (Most people watch muted.)
2. **Music:** click **Audio → Music/Sounds** → pick something calm → drag the volume down to ~15%.

### A6. Export
1. Click **Export** (top right). Choose **1080p**, **30fps**, **MP4**.
2. Wait for the download. You now have one video file.

> 📱 **Prefer your phone?** Do the whole thing in the **CapCut app**: new project → add Pexels clips → add text → tap a text → "Text to speech" → auto-captions → save. Same result.
